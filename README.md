# 엔지니어링 팀 3D 프로젝트 매뉴얼

신규사원이 엔지니어링팀 업무 프로세스를 빠르게 이해하고, 담당자가 프로젝트별 진행 상태를 관리할 수 있도록 만든 정적 웹앱입니다.

## 주요 기능

- 3D 공정 라인: 수주 전부터 양산 안정화까지 20단계 업무를 3D 블록으로 시각화
- 프로젝트 관리: 프로젝트 추가, 담당자, 현재 단계, 마감일, 상태, 협력업체/PM, 이슈 기록
- 진행판: 수주 전, 수주 후, 설계·제작, 설치, 테스트, 양산 단계별 프로젝트 분류
- 캘린더: 프로젝트 마감일을 월간 달력으로 표시
- 단계 매뉴얼: 단계별 담당, 산출물, 핵심 체크, 주의사항, 체크리스트 제공
- 서류/판단 기준: 인수인계 문서와 헷갈리는 상황별 판단 기준 제공
- Gmail 작성 준비: 업무 상황별 메일 템플릿으로 Gmail 작성창 열기
- CSV 저장: 프로젝트 현황과 체크리스트 상태를 CSV로 다운로드

## 원본 반영 기준

- Notion 회의록: 엔지니어링팀 온보딩 교육 내용, 수주 전/후 프로세스, 장납기품, 승인도, 테스트, 양산 안정화, AI 활용 과제를 반영
- 엑셀 정리본: 이전 산출물의 업무 지도, 체크리스트, 서류 흐름, 판단 기준을 반영
- PPT 기준원본: 현재 작업 폴더에는 PPT 파일이 없어 미검수 상태입니다. PPT가 제공되면 문구, 순서, 디자인 기준을 추가 대조해야 합니다.

## 배포

Vercel에서 정적 사이트로 배포합니다.

- Framework Preset: Other 또는 자동 감지
- Build Command: `npm run build`
- Output Directory: `dist`

`npm run build`는 `index.html`을 `dist/index.html`로 복사합니다.

## 로컬 실행

```bash
npm run build
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.
